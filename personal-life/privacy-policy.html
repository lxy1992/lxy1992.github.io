Personal Life Privacy Policy

Effective date: May 16, 2026

Personal Life is a private personal data dashboard for iPhone and iPad. It is designed for personal use and does not operate a developer-owned analytics backend, advertising service, or account system.

Data The App Can Access

Personal Life can access the following data only after the user grants permission or configures a connection:

  • HealthKit data, including activity, sleep, vitals, body measurements, workouts, water intake, caffeine intake, and related health metrics.
  • Location data, including current location fixes and iOS visit events used to build a private location timeline.
  • Wakapi coding activity from a user-supplied Wakapi server URL and API token.
  • App settings such as connection state, sync coverage, saved places, and display preferences.

How Data Is Used

The app uses this data to show personal dashboards, timelines, trend charts, and lightweight insights. HealthKit, location, and Wakapi data are not used for advertising, tracking, or third-party analytics.

Storage And Sync

Personal Life stores data locally on the device using Apple's local storage frameworks. The app does not sync imported HealthKit, location, or Wakapi data through iCloud or CloudKit, and the developer does not run a separate server that receives this data.

Wakapi credentials are used only to connect to the Wakapi server configured by the user. The server address, username, and API token should belong to the user or a service the user controls.

Sharing

Personal Life does not sell personal data and does not share HealthKit, location, or Wakapi data with advertisers or data brokers. Data may be processed by Apple services that are part of iOS, HealthKit, TestFlight, or App Store distribution.

Data Deletion

Users can delete local app data from Settings > Local Data > Delete Local Data inside the app. This clears imported HealthKit, location, and Wakapi data from the device, removes local sync state and Wakapi credentials, and pauses continuous location tracking. Users can also delete app data by deleting the app from their devices. HealthKit permissions can be changed in the iOS Health app or iOS Settings. Location permissions can be changed in iOS Settings.

Contact

For TestFlight builds, use the feedback address configured in App Store Connect or the TestFlight feedback flow.
